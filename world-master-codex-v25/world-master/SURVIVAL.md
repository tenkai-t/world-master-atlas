# 間違えるまでチャレンジ

## ルールと対応範囲

ホームの専用カード、各分野の「遊び方」、通常ランキングの専用リンクから入ります。開始画面で対象数を確認し、対象を固定・無作為化して開始します。同一問題は「分野:教材ID:出題形式」で識別し、重複は除きます。総合では各教材を一つの出題形式に割り当てます（国旗・首都名・地形名・世界遺産地図）。時間制限、ヒント、開始後の入力方式切替はありません。

初回不正解と「わからない」で終了。そこまでの正解数が成績です。対象全問正解は全問制覇です。途中終了は中断として履歴だけに残し、ランキングに入れません。不正解の解説を確認後に結果へ進みます。

端末内は既存の4分野の出題形式・かな/漢字手書き・キーボード・地図を再利用します。回答は既存のrecords/channelsへ反映され、復習・習熟度・勲章の既存条件に従います。challenge=survivalなので通常テスト累計には入りません。オンラインは既存公式挑戦と同様にサーバー上で採点し、専用履歴/成績を記録します。通常学習のrecordsへオンライン結果を二重に加算しません。

オンラインは国旗4択/国の位置、首都名4択、地形名4択、世界遺産地図4択、およびその名前問題の総合です。難易度、地域、地形/遺産分類、総合の国レベルを選べます。回答方法を変更して投稿するAPIはありません。ゲストは端末の一時挑戦とランキング閲覧のみです。

## 保存互換性

既存のlocalStorageキー、安定プレイヤーID、名前、PIN、オンライン操作鍵、バックアップのformat/versionを維持します。個人学習データの任意追加フィールドsurvival(version=1)に専用bests/historyを保存。新モード履歴は最大300件、自己ベストは別保存です。旧バックアップにはこのフィールドがなくても正常です。オンライン鍵・PINはバックアップへ追加しません。

端末内の進行は学習専用チェックポイントとして同じ個人データに保存。再読み込み・プレイヤー切替は中断として処理し、部分成績を登録しません。保存済みの回答記録は残します。本人/先生が既存の「学習記録を初期化」を明示的に実行した時だけ、この追加フィールドも初期化します。通常の更新・教材修復では消去しません。

教材版（リリース版）が変わった場合の端末内ベストの引き継ぎ（2026-11-04追加）：同じプレイヤーの端末内ベスト（source=local）に限り、条件（config）が完全に一致し、現在の教材で再計算した確定対象ID一覧が旧ベストの対象一覧と完全に一致するときだけ、現在の版の条件キーへベストを複写します。達成日時と成績は元のまま保持し、旧版のベストも消しません。対象が1問でも異なる場合や、オンライン成績は引き継ぎません。サーバー側ランキングの分離（departmentキー）は変更しません。

条件の固定（2026-11-04追加）：間違えるまでチャレンジの難易度は最上位のみ（国・国旗はマスター＝countryMaster、その他は発展＝advanced、総合は発展＋国のマスター）、地域は世界全体のみとします。専用ランキング（端末・自分の記録・オンライン）もこの固定条件だけを表示し、それ以外の条件の既存ベストはデータに保持したまま一覧に出しません。サーバーのカタログ・検証は従来どおり全条件を受け付けます（表示と開始入口の制限であり、保存形式や条件キーは変更しません）。中断中チェックポイントの再開は従来どおり元の条件で続けます。

入口の一本化（2026-11-04追加）：間違えるまでチャレンジへの参加は専用ページ（開始画面）からのみとします。通常学習画面（学ぼう）の「遊び方」からは「間違えるまで・対象全問」を削除し、あわせて名前と動きの似た「連続正解チャレンジ」も選択肢から外しました。学ぼう画面の遊び方は「れんしゅう／テスト／タイムアタック」のみです。連続正解チャレンジの過去の記録の扱いは、下記の「選べない条件の記録の削除」に従います。

選べない条件の記録の削除（2026-11-05追加）：ランキングページを開いたときに、現在選ぶことのできない条件の記録を端末内データから削除します（purgeUnselectableRecords）。学習側は、ランキングに載る種類の履歴（テスト形式・復習でないもの）のうち、地域が世界全体でない・問題数が10問でない・連続正解チャレンジのものを削除し、自己ベストは残った履歴から再構築します。間違えるまで側は、固定条件（最上位・世界全体）以外のベストと履歴を削除します。進行中の挑戦（チェックポイント）は対象外です。サーバー側（オンラインランキング）の記録は対象外で、従来どおり残ります。

オンラインの再開ポインターは追加のsessionStorageキーworld-master:survival:v1にプレイヤーごとに保存します。内容はrun IDと未確定回答だけで、操作鍵やPINは含みません。元のworld-master:officialは変更しません。元のプレイヤーだけが操作鍵でサーバーのrunにアクセスできます。

## ランキング条件とDB

新しいDDL・DB移行は不要です。既存player_ranking_runs/player_ranking_scoresのdepartmentをsurvival:<条件SHA-256>、versionをworld-2026-10-v7:survival-v1として分離します。既存の6部門・旧アカウント成績とはキーが重ならず、旧APIからの採点も拒否します。元のSQL/schema/journalは変更しません。

条件はルール版・既存DATA_VERSION・教材/アプリ識別子・正規化された選択条件・確定対象ID一覧で定義します。端末内とオンラインは採点元も分離します。時間を順位には使わず、連続正解数が同じなら同順位。表示順は達成日時と安定プレイヤーIDです。自己ベストは正解数が増えた時だけ置換し、同点や低い成績では日時を更新しません。全問制覇も表示します。

旧教材版の挑戦はそのスナップショットのまま再開し、旧条件の成績として保存。結果画面/自分の記録からその条件のオンライン順位を参照できます。更新後の新しい条件と混ぜません（端末内ベストの同一対象引き継ぎは上記の例外）。教材ID自体が将来廃止された場合、表示教材が不足する可能性はあり、現仕様の項目ID維持が前提です。

専用ランキングの表示（端末内・オンライン共通）は上位10位までとします（同点は同順位のため、10位が同点の場合は全員表示）。自分の順位表示は10位以下でも従来どおり示します。サーバーの保存・順位計算・返却範囲は変更しません。

教材版をまたぐ表示統合（2026-11-04追加）：端末内ランキング（この端末のみんな／自分の記録）では、教材版（material）だけが異なり、条件（config）・出題対象がすべて同じベスト同士を、1つのグループに統合して表示します。同じプレイヤーの記録が複数版にあれば、その中で最も良い記録（同点なら早い達成日）だけを載せます。統合したグループの条件名には「教材は複数版を統合」と示します。保存データやキーは変更しません。

端末／オンラインの統合とオンラインランキングの版統合（2026-11-04追加）：上記のグループ化では端末／オンラインの別も問わず、条件と対象が同じならオンラインで達成した記録も端末の記録と同じランキングに載せます（グループ名は「端末＋オンライン」等と表示）。

ランキングページへの統合（2026-11-04追加）：間違えるまでのランキングは独立画面をやめ、通常のランキングページ下部のセクション（#svRankSection）として表示します。各入口（ホーム・開始画面・結果画面）はランキングページの当該セクションへ移動します。

オンラインランキングのサーバー側統合（2026-11-04追加）：survival-leaderboard（boardKey未指定時）は、教材版だけが異なり条件・出題対象が同一の部門（department）をサーバー側で探して統合返却します（mergedFrom で部門数を返す）。これにより他の端末・旧版で達成したオンライン記録も現在のオンラインランキングに載ります。プレイヤーごとに最良の記録を採用し、順位は統合後に計算します。boardKey指定時は従来どおり単独部門のみ。保存形式・スコア登録方法は変更しません。

## サーバー採点と再開

開始時に全順序・選択肢・正解をサーバーで固定し、クライアントには現在の1問だけ送信します。対象一覧には教材IDを含みますが、未来の問題の順番/問題ID/正解対応表は送信しません。得点、終了理由、順序、本人、選択肢はサーバーで検証します。同じ回答の再送は同じ確定状態を返し、別回答への変更は拒否します。不正解確定後は再読込しても進めません。中断終了もサーバーで確定し、ランキング登録を除外します。

新モードには経過時間による失効を設けず、元の公式挑戦の1時間制限を適用しません。runは明示終了後も採点/再送に必要な情報として保持し、自動削除を追加しません。sessionStorageのポインターはそのタブを閉じると失われる可能性があります。全ブラウザ終了後の自動再開まで保証する仕様ではありません。開始回数制限は既存の30回/時を共有します。

既存の操作鍵、プロフィール改訂、CSRF/Origin検証、サーバー採点、PIN・自動ロック・複数タブ保護を再利用。APIリクエスト中のCREATE TABLE、実データ取得/コピー、元Sitesへの公開やアクセスは行いません。

## 検証・公開

npm test は既存20本+Cloudflare+新モードの22本。npm run test:survivalで新モードだけを確認できます。npm run build:cloudflareと生成設定のwrangler deploy --dry-runで公開前検証を行います。

公開先は既存Cloudflare Worker world-master-atlas / 専用DB world-master-atlas-db。GitHub mainの更新による自動公開を利用し、元のChatGPT Sites版にはpush/deployしません。公開サイトへの人工のランキング投稿は行いません。
