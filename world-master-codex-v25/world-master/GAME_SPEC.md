# 現在のゲーム仕様（第25版）

## Cloudflare版の追加仕様（2026-10-28、ローカル検証段階）

`WM_AUTH_MODE=player-key` の場合、外部アカウントへのログインの代わりに既存の256ビット操作鍵でサーバーが本人を確認します。既存のオンラインプレイヤーID・操作鍵・保存キー・学習バックアップ形式を変更しません。ゲストは閲覧のみで、登録・投稿は不可です。開始上限30回/時はアカウント単位ではなく操作鍵単位です。ブラウザの保存領域を失うとオンライン記録の操作権限は復元できません。学習バックアップに操作鍵を追加しません。元のSites版アカウントを推測して結び付けず、旧アカウントの行を自動で新しい所有者に変更しません。新規D1上の記録と既存Sitesの記録は別です。`WM_AUTH_MODE`未設定では元のSites向け認証を維持し、未対応ホストでは認証APIを停止します。詳細はCLOUDFLARE.md。

## 回答と遊び方

4択、キーボード、かな手書き、漢字手書き（ベータ）、地図タップ。すべての形式で全入力方法を使うわけではなく、位置は地図、所在国・分類は選択などの回答方針を適用します。日本語・かな・英語・登録済み別名を扱い、似ているだけの名前は自動で正解にしません。

練習、ヒントなしテスト、復習、時間制限・連続正解チャレンジ、分野を組み合わせる総合チャレンジ、結果画像の作成・共有。通常テストの回答数・正答率は他の学習モードと分けて累計します。ヒントは段階表示と読み補助。漢字モデルは対応2,213字で、候補を確認して確定します。筆跡を外部サービスに送信する方式ではありません。

地図はSVG形状・小国の補助・ズーム/パン/ピンチを使用。地形等の表示は学習上の近似を含みます。スマホ・タブレットの回答入力、IME、スクロール、指による操作を考慮しています。

## プレイヤーと保存

起動時に本人を選びPIN入力、またはゲスト。名前は20文字まで・絵文字なし、アイコン68種類。登録上限は1端末500人。初期の旧データのID等を維持して移行します。

本人用PINは数字4〜10桁、先生用は6〜64桁。先頭0を保持し、長すぎる入力を勝手に切り詰めません。PBKDF2-SHA256/600,000回の検証情報と先生復旧コードを学習バックアップから分離。自動ロックは先生が1・3・5・10・15・30・60分から設定、初期5分。時間制限問題はロック中も時間が進みます。

通常学習の記録はブラウザlocalStorage。Web Locksとrevisionで複数タブ・保存失敗を扱います。ゲストは終了・再読み込みで消え、登録プレイヤーの保存領域を書き換えません。先生は名前・アイコン、PIN、ロック時間、バックアップ、記録初期化・削除を管理します。

学習の途中経過・入力保持・復習情報は既存コードの範囲を維持します。ページを閉じた全モードを必ず同じ問題途中から再開できる、という新しい保証は付けません。公式挑戦の中断情報はsessionStorageに保存し、元のプレイヤーだけが再開できます。

| キー/形式 | 用途 |
|---|---|
| `world-master:v1` | 旧1人用データ |
| `world-master:players:v1` | 登録一覧・安定ローカルID |
| `world-master:player:v1:<id>` | 個人の学習データとrevision |
| `world-master:security:v1` | 本人・先生の保護設定とロック時間 |
| `world-master:security-attempts:v1` | 入力失敗回数・待機 |
| `world-master:online-players:v1` | オンライン識別情報・操作鍵・プロフィール送信待ち。バックアップとは別 |
| `world-master:official`（sessionStorage） | 公式挑戦の再開・未確定回答 |
| `world-master-player` / `world-master-players` version1 | 個人/全員の学習バックアップ。旧形式の読み込みも維持 |

バックアップ読み込みは新しいローカルIDとして追加し、既存記録を上書きしません。本人保護・オンラインの操作鍵は引き継ぎません。勲章・習熟度・称号等の表示条件はコードと現在の保存構造をそのまま保持し、移行準備で再計算・変更しません。

## ランキング

「この端末のみんな」「オンライン」「自分の記録」の3区分。端末内は完了済みの同条件のテスト・チャレンジから1人1件の自己ベストを比較。練習、復習、途中終了、ヒントあり、回答方法変更、条件不明の旧履歴は比較対象外。最高記録 `rankingBests` は履歴最大300件と別に保持。自分の履歴は本人の画面に限定します。

オンラインはサイトの認証済みアカウント＋不変のオンラインプレイヤーID＋256ビット操作鍵で確認。6部門：国旗10問（レベル③・4択）、国の位置10問（レベル③）、首都10問（基本・4択）、地形10問（発展・4択）、世界遺産10問（基本・4択）、総合20問（発展／国はマスター・4択）。世界全体・ヒントなし・回答方法固定、開始から1時間で失効。アカウント当たり1時間30回の開始制限。

採点・問題順・重複送信をサーバーで検証。正解数のみで順位を決め、同点は同順位、表示は達成日時と安定ID順。上位20件外でも本人の順位を取得。プロフィールは得点から独立し、名前変更で得点や達成日時を変えず、通信復帰後のキュー同期・再送を行います。旧アカウント単位のランキングは旧条件別に閲覧のみで保持。ゲストは投稿・公式挑戦不可。

## PWAと依存関係

`manifest.webmanifest`、`sw.js`、`offline-manifest.json`、`release.json`等でオフライン教材を管理。基本教材245ファイル、世界遺産写真108ファイル、漢字モデル5ファイル（この版のマニフェスト実数）。初回はオンラインで準備し、写真/漢字モデルは追加パック。ハッシュ検証、保存失敗・容量不足・欠損修復、明示的な版切り替え、旧タブの教材固定を行います。

写真未保存ならオフラインの写真問題から除外。オンラインランキング・認証・出典サイトには通信が必要。SWキャッシュと学習データは別管理です。

本体はHTML/CSS/クラシックJS、サーバーはVinext/React/Vite/Cloudflare Workers/D1/Drizzle。現在の正確な依存バージョンはpackage.jsonとpnpm-lock.yaml。フォント、写真、国旗、地図、手書きモデルのライセンスと出典を同梱しています。
