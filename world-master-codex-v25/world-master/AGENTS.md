# Codex開発ルール：世界マスター

## 作業の基準

これは公開中の世界マスター第25版を引き継ぐリポジトリです。作り直しや簡易版への置き換えをしないでください。最初にREADME.md、GAME_SPEC.md、MIGRATION.md、TEST_REPORT.mdと実際の最新ソースを読みます。過去の監査資料だけで現在の実装を断定しません。

この引き継ぎでは、本番公開・本番DBへのアクセス・実データ取得・設定変更は許可されていません。その後のユーザー指示がある場合は、その範囲に従ってください。

## 保存互換性と本人保護

- 既存プレイヤーID・保存キー・問題ID・バックアップ形式を保持する。
- localStorage/sessionStorageの消去、既存プレイヤーの作り直し、データ初期化で不具合を回避しない。
- 本人のPIN、先生用管理、自動ロック、入力制限、保存失敗時の停止、Web Locksと改訂番号による複数タブ競合保護を維持する。
- ゲストは永続保存せず、オンライン挑戦・投稿を許可しない。
- 学習記録、通常テスト累計、ランキング用自己ベスト、履歴、復習・勲章の記録を混同しない。
- 累計や自己ベストを履歴300件制限だけに依存させない。
- バックアップ読み込みは新規プレイヤーとして追加する現仕様を維持。復元でオンラインID・操作鍵やPINを自動複製しない。

## オンライン

- ランキングはアカウントだけでなくプレイヤー別。安定IDと操作鍵、認証済みアカウントをサーバーで照合する。
- クライアントが送る得点や任意のプレイヤーIDだけを信用しない。採点・順序・期限・再送をサーバーで検証する。
- 名前・アイコンはプロフィールに分離。名前変更で得点・達成日を変えない。古い挑戦で古い名前へ戻さない。
- 旧アカウント単位の記録は旧ランキングとして保持し、持ち主を推測して新プレイヤーへ割り当てない。
- 現行の同点順位・時間を順位に使わない採点を維持する。
- 本番DB行、プレイヤーIDの実値、復旧コード、操作鍵、PIN検証値、APIキー、トークンをログ・チャット・Git・テスト資料へ出力しない。
- 開発用模擬認証ヘッダーは本番の認証ではない。Sites外へ出すとき、任意のHTTPヘッダーを本人確認として信用する構成を公開しない。

## ゲームと教材

依頼にないゲームルール、難易度、採点、教材の置換・縮小をしない。国の位置付け、首都の役割、地形の近似、世界遺産の所在国等の扱いと出典・ライセンスを維持。旧モードの互換処理を勝手に削除しない。

`public/play.html`にあるクラシックスクリプトの順番を守る。各ファイルが前の関数を拡張しているため、順序変更・モジュール化は影響を確認する。回答確定、IME、手書き候補、地図タップ・ドラッグ・ピンチを検証する。

PWAでは教材と学習記録を分離。更新確認、ハッシュ検証、旧タブの教材固定、修復、明示的な再起動を維持する。教材削除で学習記録・保護設定を削除しない。

## 開発・検証

- Node24.x推奨、pnpm11.25.0、固定ロックファイルを使用。
- 通常：`npm run dev`、`npm test`、`npm run build`。テストは人工データだけで実施。
- `tests-offline-recovery.cjs` と `tests-update-migration.cjs` は同梱の履歴ソースfixtureを利用。Git履歴や本番へのアクセスを前提に戻さない。
- SW/教材変更時は `node scripts/build-release.cjs` または `npm run build` で識別情報を再生成。アプリ表示のためだけにDATA_VERSIONやランキング条件を変えない。
- D1移行は `db/schema.ts` とDrizzleを使い、適用済みSQL・snapshot・journalは不変とする。テーブル作成をAPIリクエスト中に実行しない。
- `.env*`、`.dev.vars*`、`.wrangler/`、`.sites-runtime/`、node_modules、dist、Git認証設定、DBファイルはコミットしない。
- 本番への接続権限・秘密情報をテストのために追加しない。エクスポートAPI、認証回避、無断の公開・DB移行を追加しない。
- 変更内容・理由・実行した検証・未確認事項を報告する。DOM/SW/SQLiteの模擬テストと実機検証を区別する。
