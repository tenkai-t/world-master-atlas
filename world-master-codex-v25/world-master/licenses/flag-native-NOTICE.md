# Native flag SVG provenance

204 SVGs in `dist/assets/flags-native` are untouched files from
https://github.com/hampusborgos/country-flags at revision
`c09927e63705529bbf59ca6684cd9b23225dddad`.
The upstream README states that its Wikimedia Commons-derived flags are in the
public domain. An exact copy of that README accompanies this notice.
Per-file source URLs and SHA-256 hashes are in `dist/assets/flag-ratios.json`.
No fixed 4:3/1:1 icon has been stretched to produce these assets.

`XNC.svg` is the original 900×600 SVG downloaded from
https://upload.wikimedia.org/wikipedia/commons/1/1e/Flag_of_the_Turkish_Republic_of_Northern_Cyprus.svg?download=1
File page: https://commons.wikimedia.org/wiki/File:Flag_of_the_Turkish_Republic_of_Northern_Cyprus.svg
Credit: Mike Rohsopht and Wikimedia Commons file-history contributors.
Licensed CC BY-SA 4.0: https://creativecommons.org/licenses/by-sa/4.0/
The file page also marks the flag as public-domain simple geometry.
No changes were made to the source SVG. The file history identifies the current
2021-07-11 revision, correcting star placement against the construction sheet.

Flags and official insignia can be subject to use restrictions independent of copyright.
